# 外觀

開啟**設定 → 外觀**，配置 Agora 的主題、動效、聊天顯示和字型。

## 主題與配色

- **主題模式**可跟隨裝置，或固定為淺色／深色。
- **AMOLED** 在淺色主題中使用純白背景，在深色主題中使用純黑背景。卡片和對話框保留配色層次，裝飾性背景光斑與漸層隱藏。預設關閉，切換後立即生效，並隨設定一同備份。
- **動態取色**僅在 Android 12 及以上可用。啟用後使用系統調色盤，並停用手動配色與配色風格選擇。
- **配色**選擇 Agora 調色盤，**配色風格**調整該調色盤的套用方式。

## 動效與回饋

- **模糊效果**作用於聊天清單頂部工具列下方；關閉可降低繪製成本。
- **減少動效**減少持續運動和大範圍空間位移，同時保留淡入淡出、直接手勢和必要的狀態回饋。
- **觸覺回饋**控制已支援的震動回饋。

## 聊天顯示

- **始終貼底**在回覆生成時自動跟隨新增內容。
- **解析 $…$ 行內公式**控制單一美元符號表達式；關閉後按一般文字顯示，其他數學分隔符號不受影響。
- **思考與工具區塊**提供時間軸與分組兩種模式。分組保留時間順序，並合併連續的思考、工具和圖片區塊。已儲存的精簡模式與舊設定備份會自動使用分組。
- **思考片段**選擇以卡片或 Bottom Sheet 開啟。僅當「思考與工具區塊」為「分組」時顯示。
- **自動展開目前群組**僅在「分組 + 卡片」組合下可用；它會展開目前群組，並在模型進入下一階段時收合。

## 字型

可選擇 Agora 內建字型、系統字型或自訂字型。只有選擇**自訂**時才顯示檔案選擇項。Agora 會驗證匯入的字型檔案並拒絕無效檔案；切換離開自訂字型會刪除由 Agora 管理的匯入副本。
