# 生成参数

打开**设置 → 生成参数**配置默认请求参数；对话级覆盖可替换这些默认值。

## 常用参数

- 温度控制随机性。
- Top P 限制累计概率质量。
- Top K 在提供商支持时限制候选 Token。
- 最大输出 Token 限制回复长度。
- 频率惩罚和存在惩罚在支持时降低重复。

Agora 只会按所选提供商协议发送受支持的参数。

## 思考

可启用思考预算并选择 Token 预算，或选择模型支持的推理等级：**Minimal、Low、Medium、High、xHigh、Max**。不同提供商与模型的支持不一致。

## OpenAI 兼容服务层级

兼容端点可选 **Off、Auto、Default、Flex、Fast**。是否可用、延迟与计费由提供商决定。

## 图像质量
图像质量作用于 Agora 新处理的模型输入图片，包括附件、工具图片、生成图片、Phone 截图、PDF 页面和视频帧。可选轻量（最长边 1024 px、JPEG 75）、均衡（2048 px、JPEG 80，默认）、高清（4096 px、JPEG 95）或自定义。自定义最长边范围为 128 至 8192 px，JPEG 质量为 1 至 100。设置即时保存，切换预设会保留自定义值。透明图片使用 PNG，已有栅格图片不会被放大。

修改质量只影响后续处理。已完成的附件、历史图片以及排队或重试中的请求继续使用原有图片字节。PDF 和视频批次沿用开始处理时的设置。Remote 会话图片保留收到的原始字节。
