# 网络代理

打开**设置 → 网络代理**，让 Agora 共享 HTTP 客户端的流量经过指定代理。

## 作用范围

代理可能覆盖提供商请求、模型同步、网络搜索、HTTP MCP、更新检查，以及用户明确提交的评分/崩溃报告。它不会透明代理：

- 直接 SSH 连接
- 设备端 llama.cpp 推理
- Alpine 沙盒进程的网络

## 代理类型

- **HTTP**——明文 HTTP 代理。Agora 对 `https://` 目标发送 `CONNECT` 建立隧道，对 `http://` 目标发送绝对形式的请求。代理地址和代理凭据在本地网络路径上可见。
- **HTTPS**——协议相同，但 Agora 会先与代理本身建立 TLS 连接（例如 Caddy 的 `forward_proxy`，或监听 `https_port` 的 Squid）。`CONNECT` 请求、目标主机名和代理密码在设备与代理之间均被加密。代理证书必须对所配置的主机有效，并被 Android 系统信任库信任。
- **SOCKS5**——SOCKS5 代理，支持可选的用户名/密码认证。

可配置代理类型、主机、端口、可选用户名/密码和绕过规则。代理密码只有在导出时明确选择机密/API Key 类别才会写入归档。
