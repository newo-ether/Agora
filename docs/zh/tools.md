# 代理工具

Agora 可让模型在多轮生成中调用工具。

按设置、构建和提供商能力，可用工具包括：网络搜索、图像生成、活跃/已保存记忆、历史对话搜索、MCP、任务与循环自动化、Conch/SSH 命令与持久任务、远程文件操作、`file_view_image`，以及 F-Droid 构建中的 Alpine 沙盒。

## 手机操作

在「设置 → 工具 → 手机操作」中，「最多保留截图」默认为 5 张。滑块可选 1–16 张，16 右侧是「不限」。选择数字时，只向模型发送最近的相应数量的内置手机操作工具图片；选择「不限」时，不按张数裁剪这些图片。修改只影响新开始的生成，不删除对话中的截图，也不影响用户附件、生成图片或其他工具的图片。

## 向用户提问

交互设置可控制模型是否能向你提问。阻塞式提问默认等待 5 分钟；超时时间滑条提供 1、2、5、10、15、30、60 分钟七档，松手后自动保存。同一组问题共用一个时限。超时后保留已提交回答，其余问题返回“未回答”。非阻塞提问会在模型继续工作时保留，等待你回答。修改设置只影响新开始的生成。

## 权限与默认值

网络搜索、活跃记忆、已保存记忆、历史对话访问和全局 Shell 权限默认开启；Shell 仍需先配置设备，并遵循该设备的确认策略。自动化工具默认关闭。MCP 按服务器与工具开关控制。

工具调用和结果会进入对话协议，并可能在后续轮次发送给模型。外部工具会收到执行所需参数，启用前应核对服务器和权限。图像生成与嵌入使用各自所选提供商的凭据。
