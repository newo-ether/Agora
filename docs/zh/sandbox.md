# 本地沙箱

集成的 PRoot 环境可在设备上执行 Linux 命令。可选择 Alpine、Debian 或 Ubuntu；每个发行版保留独立的 Linux 系统和已安装的软件包。

## 可用性

本地沙箱仅在 F-Droid 构建中提供。Google Play 构建不提供本地沙箱执行能力。

## 选择和安装发行版

进入**设置 → 终端 → 管理本地沙箱**，在**环境信息**中的**发行版**选择 Alpine、Debian 或 Ubuntu。选择立即生效，并保存在当前设备。已有安装默认继续使用 Alpine，直到你主动选择其他发行版。

选择尚未安装的发行版不会自动下载。点击其面板中的**安装**才会下载并安装 Linux 系统。切回已经安装的发行版时，无需重新安装。同一时间仅有一个发行版处于选中状态；切换前需停止运行中的沙箱任务，并等待系统安装或软件包操作完成。

## 软件包和文件

面板显示当前发行版及版本。可通过现有控件安装、移除或升级软件包。快速安装列表使用对应发行版的包名：Alpine 使用 `apk` 和 `build-base`，Debian、Ubuntu 使用 `apt` 和 `build-essential`。已安装的软件包属于各自的发行版。

所有发行版共享 `/home/agora`，包括附件和工作文件。切换不会复制或删除这些文件。发行版中的程序、虚拟环境和编译产物可能依赖该发行版，切换后可能需要重新安装。

面板显示当前 Linux 系统与共享 home 目录的近似文件大小，包括附件，不计入共享存储。沙箱没有强制的 2 GB 配额，实际可用空间取决于设备剩余存储。

**浏览文件**可在系统文件管理器中打开沙箱。可选的**共享存储**访问会把设备共享文件挂载到 `/mnt/shared`；授权后，沙箱命令可以读取和修改这些内容。

## 重置环境

**重置环境**只删除所选发行版的 Linux 系统及其已安装的软件包。共享 home 文件和其他发行版会保留。删除无法撤销；如需该发行版的全新系统，可再次点击**安装**。

## 安全边界

PRoot 提供 Linux 用户态环境，不提供独立内核或硬件虚拟机，也不会获得 Android Root。命令仍可使用应用已经获得的权限。VPN、私有 DNS、门户网络或 Android 后台策略可能影响下载与联网。
