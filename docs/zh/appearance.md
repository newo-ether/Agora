# 外观

打开**设置 → 外观**配置 Agora 的主题、动效、聊天展示和字体。

## 主题与配色

- **主题模式**可跟随设备，或固定为亮色/暗色。
- **AMOLED** 在浅色主题中使用纯白背景，在深色主题中使用纯黑背景。卡片和对话框保留配色层次，装饰性背景光斑与渐变隐藏。默认关闭，切换后立即生效，并随设置一同备份。
- **动态取色**仅在 Android 12 及以上可用。启用后使用系统调色板，并停用手动配色与配色风格选择。
- **配色**选择 Agora 调色板，**配色风格**调整该调色板的应用方式。

## 动效与反馈

- **模糊效果**作用于聊天列表顶部工具栏下方；关闭可降低渲染开销。
- **减少动效**减少持续运动和大范围空间位移，同时保留淡入淡出、直接手势和必要的状态反馈。
- **触觉反馈**控制已支持的振动反馈。

## 聊天展示

- **贴底跟随**在回复生成时自动跟随新内容。
- **将 $…$ 解析为行内数学公式**控制单美元符号表达式；关闭后按普通文本显示，其他数学分隔符不受影响。
- **思考与工具块**提供时间线与分组两种模式。分组保留时间顺序，并合并连续的思考、工具和图片块。已保存的紧凑模式与旧设置备份会自动使用分组。
- **思考片段**选择以卡片或 Bottom Sheet 打开。仅当“思考与工具块”为“分组”时显示。
- **自动展开活动分组**仅在“分组时间线 + 卡片”组合下可用；它会展开当前分组，并在模型进入下一阶段时收起。

## 字体

可选择 Agora 内置字体、系统字体或自定义字体。只有选择**自定义**时才显示文件选择项。Agora 会验证导入的字体文件并拒绝无效文件；切换离开自定义字体会删除由 Agora 管理的导入副本。
