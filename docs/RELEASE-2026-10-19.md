# Agora — Kalamos fork: Android preview, 19 October 2026

Release tag: `v2026.10.19-preview.1`. ARM64 tablet builds; Notes and KOReader require Android10+;
Agora requires Android8+. These are developer/debug-signed previews, not store-signed upstream releases.
An existing installation signed with another key cannot be updated in place. Back up local data
before changing application variants or installations. No on-device testing was performed for this
release packaging; physical pen/panel testing belongs to the owner.

## Build and source

Use JDK21, Android SDK36 and NDK28.2.13676358. Initialize the recorded Git submodules.
Build the ARM64 full-capability F-Droid variant with the standard application ID:
`bash ./gradlew -I tools/generic-android-preview.gradle :app:assembleFdroidGenericPreview`.
Output: `app/build/outputs/apk/fdroid/genericPreview/app-fdroid-genericPreview.apk`.
The application ID is `com.newoether.agora`; the launcher name identifies the Kalamos fork.
This APK works on generic Android and Bigme; e-ink settings are available in the app.
This is independently maintained, not an official upstream Agora release. Upstream GPL and notices remain intact.
The matching source bundle includes the pinned llama.cpp and PRoot submodules, unlike GitHub's automatic source ZIP.

Release assets include APKs, a matching source archive, component licence notices and SHA256SUMS.txt.
Signing private keys, notebooks, API credentials and local build configuration are excluded.
